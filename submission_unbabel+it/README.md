Our systems are based on Tower-7b models and and are trained on the chat datasets released by the shared task. Our *primary* system uses Contextual MBR re-ranking to get the best hypothesis, the two other contrative systems are as follows: 1. *contrastive1* is a 70b variant of the Tower model specialized to have general purpose translation capabilities. 2 *contrastive2* uses greedy decoding with the 7b model finetuned on chat datasets.

We want to use the *primary* system for human evaluation.
